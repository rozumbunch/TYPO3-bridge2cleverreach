# Installation Guide

This guide helps you install and set up Bridge2Cleverreach.

## Quick Start

1. Install the extension via Composer
2. Enable the Site Set
3. Enter the CleverReach API credentials
4. Add Subscribeform or Unsubscribeform as a content element

## Requirements

- TYPO3 12.4+ / 13.0+ / 14.0+
- PHP 8.1+
- CleverReach API account with valid credentials
- OAuth scope `oa_flows` (plus `oa_forms` for legacy numeric Form IDs)
