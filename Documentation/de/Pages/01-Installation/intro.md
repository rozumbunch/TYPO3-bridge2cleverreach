# Installationsanleitung

Diese Anleitung hilft bei der Installation und Einrichtung von Bridge2Cleverreach.

## Schnellstart

1. Extension per Composer installieren
2. Site Set aktivieren
3. CleverReach-API-Zugangsdaten eintragen
4. Anmeldeformular oder Abmeldeformular als Inhaltselement anlegen

## Voraussetzungen

- TYPO3 12.4+ / 13.0+ / 14.0+
- PHP 8.1+
- CleverReach-API-Account mit gültigen Zugangsdaten
- OAuth-Scope `oa_flows` (plus `oa_forms` für bisherige numerische Formular-IDs)
