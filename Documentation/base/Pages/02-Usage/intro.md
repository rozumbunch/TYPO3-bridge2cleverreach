# Usage

Configuration is available in two ways:

- modern approach via **TYPO3 Site Sets / Site Settings Overview**
- classic approach via **TypoScript static templates / Constant Editor**

API credentials and recipient lists remain in the **Site Configuration** (tab *Cleverreach*).
