# Nutzung

Die Konfiguration ist auf zwei Wegen möglich:

- moderner Weg über **TYPO3 Site Sets / Site Settings Overview**
- klassischer Weg über **TypoScript-Static-Templates / Constant Editor**

API-Zugangsdaten und Empfängerlisten bleiben in der **Site Configuration** (Reiter *Cleverreach*).
